## Vrinda Store Data Analysis Project

An end-to-end data analytics project focused on cleaning, processing, and analyzing e-commerce retail data to build a dashboard in Microsoft Excel.

## Objective
To analyze Vrinda Store's annual sales data for 2022 and generate business insights regarding customer profiles,sales channels, and geographic performance to drive future growth.

## Tech Stack
Tools: Microsoft Excel (Advanced Formulas, Pivot Tables, Pivot Charts, Slicers)
Skills: Data Cleaning, ETL Frameworks, Business Intelligence

## Project Workflow
1. **Data Cleaning:** Handled missing rows and mapped inconsistent short codes (M/W) into descriptive fields (Men/Women).
2. **Processing:** Created logical buckets for Age Groups and extracted monthly timeframes from timestamps.
3. **Data Analysis:** Aggregate metrics across Categories, Payment Modes, Order Status, and localized States.
4. **Interactive Dashboard:** Built connected Pivot Charts synced with dynamic Slicers (Month, Category, Channels) for automated updates.

## Key Insights
1. **Peak Month:** March achieved the highest monthly order traffic and revenue.
2. **Target Audience:** Female consumers form the core user base, driving roughly 65% of absolute revenue.
3. **Prime Segment:** Adult population cluster (30-49 years old) serves as the leading driver for sales.
4. **Main Channels:** Amazon, Flipkart, and Myntra dominate operations with an 80% total asset share.
5. **Top Regions:** Sales conversions are heavily concentrated within Maharashtra, Karnataka, and Uttar Pradesh.
